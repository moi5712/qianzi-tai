# 嵌字台

在瀏覽器裡做漫畫嵌字：塗掉原稿字、放入譯文、調整直排樣式，再匯出 PNG。跑在你自己的電腦上，圖不會傳到別人的伺服器。

翻譯可接 OpenAI 相容 API；文字檢測預設用本機 OCR。

## 安裝（Windows）

1. 安裝 [Python 3.10 或更新](https://www.python.org/downloads/)。安裝畫面請勾選 **Add python.exe to PATH**。
2. 下載這個專案：GitHub 頁面按 **Code → Download ZIP**，解壓縮。
3. 雙擊 `啟動.bat`。第一次會安裝套件，可能要幾分鐘。
4. 瀏覽器應會自動打開 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。沒有的話請手動開這個網址。

關掉黑色視窗即結束。下次只要再雙擊 `啟動.bat`。

已有 Python 的人也可以在專案資料夾執行：

```bat
python -m pip install -r requirements.txt
python app.py
```

## 第一次怎麼用

1. 按 **新建**，選一個空資料夾當專案（漫畫圖會放這裡）。
2. 按 **匯入圖片**，加入頁面。
3. 要用 AI 翻譯的話，打開 **API 設定**，填入 API 位址、模型與 Key（OpenAI 相容端點即可）。檢測預設走本機 OCR，不必為了辨識文字而開視覺模型。
4. 用筆刷、矩形或套索蓋住原稿字。
5. **加入**譯文，或用 **AI 翻譯** 自動辨識／翻譯。選一則對白，切到文字工具，在畫面上點一下即可放置。
6. **匯出**會把勾選的頁存成 PNG，放到專案裡的 `匯出` 資料夾。

快捷鍵：`V` 選取、空白鍵拖曳、`B` 筆刷、`E` 橡皮擦、`U` 矩形、`L` 套索、`I` 滴管、`T` 文字、`Ctrl+Z` 撤銷。

## 系統需求

- Windows 10 或 11（也可在其他系統用 `python app.py`）
- Python 3.10+
- 本機 OCR 第一次執行會下載模型，需要網路

## 不會上傳的東西

`data/settings.json`（API Key）、專案圖片、字體、塗白與匯出檔都只存在你的電腦，請不要把它們提交到 Git。

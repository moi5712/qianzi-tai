# 嵌字台

快速漫畫漢化嵌字一站式全流程工具，可直接於瀏覽器中操作，可接入 AI 模型一鍵識別內容並翻譯，所有處理均於本地完成。

## 安裝（Windows）

1. 安裝 [Python 3.10 或更新](https://www.python.org/downloads/)。安裝畫面請勾選 **Add python.exe to PATH**。
2. 下載這個專案並解壓縮。
3. 雙擊 `啟動.bat`。第一次會安裝套件，可能要幾分鐘。
4. 瀏覽器應會自動打開 [http://127.0.0.1:8765/](http://127.0.0.1:8765/) 或手動開這個網址。
5. 關掉終端機即結束。每次啟用雙擊 `啟動.bat`。

已有 Python 的人也可以在專案資料夾執行：

```bat
python -m pip install -r requirements.txt
python app.py
```

## 如何開始

1. 建立專案：點選 **新建**，選擇一個空資料夾作為專案目錄（不要選嵌字工具本身）。漫畫圖像、嵌字存檔與匯出都寫在這個資料夾。
2. 匯入漫畫頁面：按 **匯入圖片** 新增頁面。
3. AI 翻譯設定：「API 設定」中填入 OpenAI 相容 API 的位址、模型名稱與金鑰。

## 資料放哪裡

- `嵌字工具`：程式、介面、內建字體。`data` 只放應用設定（API、最近開啟的專案、自行匯入的字體）。
- 漫畫專案資料夾：頁面圖片、`.lettering`（對白／文字框、塗白、縮圖）與 `匯出`。
- 開啟或新建時請選漫畫資料夾，不要把工具目錄當成專案。

## 系統需求

- Windows 10 或 11（也可在其他系統用 `python app.py`）
- Python 3.10+
- 本機 OCR 第一次執行會下載模型，需要網路
